# Лётная школа Никиты ✈️

Тренажёр таблицы умножения для ребёнка 8 лет в «самолётной» теме. Работает в браузере на телефоне и компьютере. Нет рекламы, нет регистрации, не нужны платные сервисы. Игру можно установить на телефон как приложение, и тогда она работает без интернета.

## Что нового

**👾 Режим «Босс».** Злая туча с полоской жизни из 10 делений. Каждый правильный ответ — удар молнией по туче. 10 правильных подряд — туча лопается, Никита получает **кубок 🏆** (+50 очков и 3 звезды). Одна ошибка — туча смеётся, бой проигран, но игра сразу показывает, как решать правильно. После каждой победы приходит новый босс: Грозовая Туча → Злой Ураган → Ледяной Вихрь → Огненный Смерч → Чёрная Буря → Король Бурь.

**📝 «Мои ошибки».** Игра запоминает каждый пример, в котором Никита ошибся. На отдельном экране видно список трудных примеров с ответами. Кнопка «Повторить трудные» запускает тренировку только на них. Пример исчезает из списка, когда его решили правильно **3 раза подряд** (три кружочка под примером становятся зелёными). В обычных полётах трудные примеры тоже попадаются чаще, примерно каждый третий.

**📊 «Моя таблица умножения».** Таблица по числам от 2 до 9, по 10 примеров в каждой строке. Сначала в клетках стоят «?», а по мере решения таблица заполняется ответами:
- 🟩 зелёная клетка — «знаю» (решил правильно 2 раза подряд);
- 🟦 голубая — «учу»;
- 🟧 оранжевая — «трудный пример»;
- серая — ещё не решал.

Около каждого числа написано «знаю 6 из 10». Когда строка собрана целиком, появляется корона 👑, а если на этом числе побеждён босс — кубок 🏆. Нажмите на строку, и появятся кнопки «Учить ×7» и «Босс ×7». Ниже — полка с кубками.

**🎯 Задание дня и 📅 дни подряд.** Каждый день задание: 20 правильных ответов (это примерно 2 полёта). За него +30 очков, а счётчик «дней подряд» растёт. Пропустил день — счётчик начинается заново. Это главный повод заходить каждый день.

**🔊 Звуки.** Правильный ответ — «дзинь», ошибка — мягкий «у-у», без страшных звуков. Добавлены удар по боссу, смех босса, взрыв тучи, фанфары за кубок и искорки, когда ошибка исправлена. Кнопка 🔊 / 🔇 есть и в меню, и прямо во время игры. Выбор запоминается.

**📲 Установка на телефон.** Внизу меню — кнопка «Установить на телефон». На Android игра ставится в один клик, на iPhone откроется пошаговая подсказка. После установки на экране телефона появляется значок с самолётиком, игра открывается без адресной строки и работает без интернета.

**Мелочи:**
- кнопка «Назад» на телефоне возвращает в меню, а не закрывает игру;
- если свернуть игру в режиме «На скорость», топливо не тратится;
- объяснение ошибки стало проще: 9 × 2 объясняется как 2 раза по 9 (9 + 9), а для ×1 и ×10 есть свои подсказки;
- рекорды видны прямо на кнопках режимов.

**Прогресс не пропал.** Очки, звёзды, звание и самолёты, набранные раньше, сохранились.

## Как включить GitHub Pages (сайт с игрой)

GitHub Pages бесплатно публикует игру в интернете по адресу вида `https://sergey-bagaliy.github.io/nikita-game/`. По данным GitHub, для этого репозитория Pages уже включён. Обычно достаточно шага 1, а шаги 2–4 — проверка.

1. **Перенесите изменения в ветку `main`.** На GitHub откройте вкладку **Pull requests** → откройте запрос с этими изменениями → нажмите **Merge pull request** → **Confirm merge**.
2. Откройте репозиторий → вкладка **Settings** (Настройки) → слева пункт **Pages**.
3. В разделе **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/ (root)` → кнопка **Save**.
4. Подождите 1–3 минуты. Вверху страницы Pages появится надпись **«Your site is live at …»** со ссылкой на игру. Ход публикации виден на вкладке **Actions** (зелёная галочка — готово).

Важно: Pages бесплатен для **открытых** (public) репозиториев. Для закрытых нужен платный тариф GitHub. Этот репозиторий открытый, так что платить ничего не нужно. Источник: [docs.github.com — About GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages).

Файл `.nojekyll` в корне говорит GitHub «отдавай файлы как есть», ничего не трогать в нём не нужно.

## Как установить игру на телефон

Откройте ссылку на игру и нажмите внизу меню **«Установить на телефон»**. Если кнопка не сработала — вручную:

**Android (Chrome):** ⋮ (три точки вверху справа) → **«Установить приложение»** или **«Добавить на главный экран»**.

**iPhone (Safari):** кнопка **«Поделиться»** (квадрат со стрелкой вверх; если её не видно — сначала «⋯») → **«На экран „Домой“»** → **«Добавить»**.

Советы:
- **На iPhone лучше сразу установить игру и дальше открывать её только со значка.** У установленной игры своё хранилище, отдельное от Safari, поэтому прогресс из Safari в неё не переносится. Кроме того, Safari сам стирает данные сайтов, которые не открывались 7 дней, а на установленные приложения это правило не действует. Источник: блог WebKit (разработчики Safari), статья «Full Third-Party Cookie Blocking and More», март 2020, раздел про 7-дневный лимит хранения (webkit.org/blog).
- Если на iPhone нет звука, проверьте, не включён ли беззвучный режим.
- Чтобы игра заработала без интернета, её нужно один раз открыть с интернетом. Внизу меню появится «✅ Игра сохранена в телефоне и работает без интернета».

## Где хранится прогресс

Прогресс хранится в самом телефоне, в памяти браузера (никаких аккаунтов и серверов). Значит:
- на другом телефоне или в другом браузере прогресс будет свой;
- если очистить данные браузера или удалить установленную игру, прогресс пропадёт.

## Как обновляется игра

После изменений на GitHub телефон скачивает новую версию сам, в фоне, когда есть интернет. Новая версия включится **при следующем запуске**: закройте игру и откройте снова.

Для разработчика: после изменения файлов игры поднимите номер версии `CACHE` в `sw.js` (сейчас `letnaya-shkola-v2`).

## Как устроены правила (для родителей)

| Что | Правило |
|---|---|
| Тренировка | 10 примеров, полёт из Краснодара в случайный город, до 3 звёзд |
| На скорость | 60 секунд, сколько успеешь; рекорд сохраняется |
| Босс | 10 разных примеров из выбранных чисел подряд без ошибок → кубок, +50 очков |
| Трудный пример | ошибся → в «Моих ошибках»; 3 раза подряд правильно → уходит из списка |
| «Знаю» в таблице | 2 раза подряд правильно |
| Повтор ошибок | берёт до 4 самых трудных примеров, не больше 15 вопросов за раз |
| Задание дня | 20 правильных ответов за день → +30 очков и +1 к «дням подряд» |
| Очки | +10 за ответ, +5 бонус за серию от 3 подряд |

Все цифры настраиваются в начале файла `game.js` (раздел «Настройки»).

## Файлы

- `index.html` — страница
- `style.css` — оформление (небо, облака, анимации)
- `planes.js` — рисунки самолётов для ангара
- `boss.js` — рисунки боссов-туч
- `game.js` — логика игры, звания, ошибки, таблица, босс, звуки
- `sw.js` — офлайн-режим (при изменении файлов поднимите номер версии `CACHE`)
- `manifest.webmanifest`, `icon-*.png` — значок и название для экрана телефона
- `.nojekyll` — для GitHub Pages

Публикация на любом другом хостинге (например, Beget): скопировать все файлы в одну папку сайта. Для офлайн-режима и установки на телефон сайт должен открываться по https.

## Вторая игра: «ЯМЩИК — Валера против ям»

Папка `valera/` — аркада для взрослых: Валера на мотоцикле объезжает и заделывает ямы, карьера в ООО «Красноармейка» от гастарбайтера с лопатой до собственника, гараж мотоциклов, «Компромат» (видео за достижения), «Режим прораба» с матом (выключен по умолчанию).
Трасса с поворотами и отбойниками, деревни и города Красноармейского района (знаки, переходы, камеры, бордюры), животные по местности, персонаж Мотя (бутылки из клуба, оранжевый мотоцикл, пинает конусы, спит у отбойника, бегает с собакой), крикуны на обочине по ступеням карьеры, голоса персонажей через встроенный синтез речи (мат запикивается).
Видео кладутся в `valera/video/` с именами `1.mp4` … `7.mp4`.

### Озвучка «Ямщика»
Все фразы заранее озвучены нейросетевыми голосами (бесплатно, без интернета): Piper — Дмитрий, Денис, Руслан, Ирина; станичные персонажи говорят «балачкой» — украинская модель Piper (Лада, Микита, Тетяна); формальные — MMS (Meta) — файлы в `valera/voice/`, словарь `valera/voices.js`.
У каждого персонажа своя настройка голоса и обработка (`VOICES` в `tools/build_voices_neural.py`), ударения — словарь `STRESS` там же (номер ударного слога).
Пересобрать после изменения фраз в `valera/data.js`:

```
sudo apt install espeak-ng sox lame && pip install onnxruntime numpy
# модели vits-piper-ru_RU-{dmitri,denis,ruslan,irina}-medium, vits-piper-uk_UA-ukrainian_tts-medium, vits-mms-rus:
#   github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models  (+ pip install sherpa-onnx)
node tools/export_lines.js > /tmp/lines.json
python3 tools/build_voices_neural.py /tmp/lines.json /путь/к/моделям
```
Старый вариант на RHVoice — `tools/build_voices.py`.
