# Лётная школа Никиты ✈️

Тренажёр таблицы умножения для ребёнка 8 лет в «самолётной» теме. Работает в браузере на телефоне и компьютере, без регистрации и рекламы.

## Что умеет

- Выбор чисел от 2 до 9 (можно несколько сразу).
- «Тренировка» — полёт из Краснодара в случайный город: 10 примеров, самолёт летит по маршруту и в конце садится.
- «На скорость» — топлива на 60 секунд: сколько правильных ответов успеешь.
- 4 крупные кнопки с вариантами ответа.
- Очки (+10 за ответ, +5 бонус за 3 и больше подряд), звёзды за полёт (до 3), 10 званий: от «Пассажира» до «Легенды неба».
- Ангар: 10 самолётов (кукурузник, вертолёт, воздушный шар, лайнер, истребитель, ракета и др.) открываются с новыми званиями, можно выбрать, на каком летать.
- При ошибке — «турбулентность» и доброе объяснение через сложение: 3 × 4 = 4 + 4 + 4 = 12, с картинкой из кружочков. Пока открыто объяснение, топливо не тратится.
- Звуки создаются прямо в браузере (без файлов): взлёт, «дзинь», гудок за серию, «динь-дон» и мелодия при посадке. Кнопка 🔊 выключает звук.
- Рекорды, очки, звание и выбранный самолёт сохраняются в этом браузере (localStorage).

## Файлы

- `index.html` — страница
- `style.css` — оформление (небо, облака, анимации)
- `planes.js` — рисунки самолётов для ангара
- `game.js` — логика игры, звания, звуки

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (Settings → Pages → Deploy from a branch → main, / (root)).
