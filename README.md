# Умножайка для Никиты

Тренажёр таблицы умножения для ребёнка 8 лет. Работает в браузере на телефоне и компьютере, без регистрации и рекламы.

## Что умеет

- Выбор чисел от 2 до 9 (можно несколько сразу).
- Режим «Тренировка» — 10 примеров без спешки.
- Режим «На скорость» — сколько правильных ответов за 60 секунд.
- 4 крупные кнопки с вариантами ответа.
- Очки (+10 за ответ, +5 бонус за 3 и больше подряд), звёзды за игру (до 3), 10 уровней.
- При ошибке — доброе объяснение через сложение: 3 × 4 = 4 + 4 + 4 = 12, и картинка из кружочков. Пока открыто объяснение, таймер стоит.
- В конце игры — список примеров, которые стоит повторить.
- Рекорды, очки и уровень сохраняются в этом браузере (localStorage).

## Файлы

- `index.html` — страница
- `style.css` — оформление
- `game.js` — логика игры

## Как опубликовать (GitHub Pages)

1. Settings → Pages.
2. Source: «Deploy from a branch».
3. Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится ссылка вида `https://<имя>.github.io/nikita-game/`.
